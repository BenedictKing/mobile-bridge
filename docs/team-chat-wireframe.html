网关约定（与线框一一对应）

复用主控入口
团队聊天仍打开负责人会话；上传、时间线、权限审批和消息幂等不另建一套。

发送即创建 Run
网关识别 teamId 后只创建 single + autoPlan Run，不额外发送普通 Prompt。

高级能力不挤进输入区
显式流水线、定时 Run 和修订留在团队高级入口；Skill、目标模式和 steer 本轮不出现。

1. POST /api/sessions/:leadId/uploads
   → { id: "upload-uuid", name: "homepage.png" }

2. POST /api/sessions/:leadId/send
   {
     "id": "client-message-uuid",
     "teamId": "team-uuid",
     "text": "请按这张截图检查首页布局",
     "mode": "send",
     "workMode": "default",
     "attachments": [{ "id": "upload-uuid" }]
   }

3. 网关：Lead Task 持久化附件 → submissions → PromptWithBlocks
   → { "status": "accepted", "teamId": "team-uuid", "runId": "run-uuid" }

线框中的“附件”和“发送”只演示界面状态，不发起网络请求；“最近 Run”用于评审聊天与高级详情的边界。
